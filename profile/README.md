## 📱 About

**홍익온**은 두 가지 핵심 기능을 중심으로 만들어지는 캠퍼스 앱입니다.

- 🗺️ **지도 / 내비게이션** — 건물·시설 마커, 실내 경로 안내, 캠퍼스 내 보행자 경로 탐색
- 📢 **공지사항** — 학사공지 구독, 키워드 알림, 관심 정보만 골라 받아보기

여기에 제보 기능, 제휴업체(Partners) 정보, 즐겨찾기(Bookmark) 등 학생들의 캠퍼스 생활을 돕는 기능들을 더하고 있습니다.
